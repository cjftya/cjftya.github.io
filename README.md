# cjftya.github.io

Static GitHub Pages repository.

- `index.html`: redirects the root page to `projects/viola/`
- `projects/`: individual pages
- `projects/*/scripts/`: scripts owned by each page
- `projects/weddingcard/scripts/common/`: legacy helpers used only by weddingcard
- `shared/`: JavaScript used by multiple projects (`p5`, topic/time helpers, vector/math helpers)
