# Jelly Oasis — 신비로운 숲 색상·분위기 보완

2026-10-18

## 미술 기준

세계수의 마력이 뿌리, 호숫가, 전경 식물로 이어지는 오아시스.
로우폴리의 면과 기존 세계수 구도를 유지한다. 청록·연보라가 중심이고,
따뜻한 살구·금빛은 호수 앞쪽의 두 군락에 한정한다.
모든 지면을 밝히지 않고 군락 사이의 어두운 여백과 열린 접근로를 남긴다.

## 변경

- 14개 군락 영역에 넓은 꽃잎, 연결된 줄기·잎, 버섯 갓·주름을 생성한다.
  실제 식재는 호수·접근로·순환 동선·급경사를 피한다.
- 꽃잎과 버섯 주름만 발광하고 식물 전체를 균일하게 빛내지 않는다.
  바람은 기존 시스템을 공유하며 모바일에서도 같은 식재를 유지한다.
- 세계수의 낮은 뿌리 표면에 제한된 보랏빛 흔적을 넣는다.
- 군락 위치와 맞춘 지면 색과 지형을 따르는 부드러운 색 번짐을 추가한다.
  꽃과 버섯은 두 개의 인스턴싱 드로우로 처리하고 꽃마다 광원을 만들지 않는다.
- 기존 크리스탈 보조광의 범위를 넓히고 모바일에서도 유지한다.
- 물안개를 낮에도 약하게 보이게 하고 밤에는 더 선명하게 한다.
  공기 원근과 밤의 지면 간접광을 조정해 배경·전경을 구분한다.
- 기존 반딧불 수를 늘리지 않고 군락 주변 낮은 높이로 재배치한다.

## 복원 및 검증

최초 로컬 커밋 `0700d3d`는 공개 master 푸시 승인 대기 중 임시 공간이
정리되어 유실됐다. 사용자 승인 후 대화의 변경 기록에서 코드를 복원했다.
복원한 프로덕션 번들 `jellyOasis-wHPK4NGv.js`는 최초 검증 빌드와 동일하다.

- TypeScript 및 배포 빌드, 전체 ESLint 통과.
- 관련 6개 테스트 파일, 총 32개 테스트 통과.
- 최초 구현 당시 데스크톱/모바일 낮·해질녘·밤, 애니메이션·비·크기 변경 확인.
- 복원 후 프로덕션 빌드의 데스크톱 낮·밤, 모바일 밤 화면을 재확인.
- 캡처와 브라우저 결과: `artifacts/jelly-oasis/enchanted-understory-v1/`.
- 소프트웨어 WebGL 및 모바일 화면 모사 결과이며 실기기 FPS 검증은 아니다.
  검증 환경의 한국어 폰트 부재로 캡처의 일부 UI 글자가 사각형으로 표시된다.
