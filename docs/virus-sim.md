# Virus Sim v1

Virus Sim은 바이러스의 대표적인 외형을 3D로 살펴보고, 일반화한 꼬리 달린 DNA 파지가
단일 세균에 부착해 유전체를 전달하고 새 입자를 방출하는 과정을 조작·관찰하는 브라우저
실험장이다. 실제 유전체 서열에서 구조나 감염력을 예측하지 않으며 치료 효과를 평가하는
도구도 아니다.

## 실행과 조작

```bash
npm ci
npm run dev
```

개발 서버에서 `/projects/virus-sim/`을 연다. `npm run build && npm run preview`로 만든
결과에서도 같은 경로를 직접 열 수 있다.

- **구조 관찰**: 정이십면체형, 꼬리형 파지, 필라멘트형 프리셋을 회전·확대한다. 구조를
  선택하거나 분해 슬라이더와 단면·유전체 표시를 사용해 부품 관계를 살펴본다.
- **감염 실험**: 시드와 초기 조건을 정하고 `초기화`한 뒤 시작한다. 실행 중 바꾼 초기
  조건은 현재 세계를 변경하지 않고 다음 초기화에 적용한다.
- **관찰 제어**: 시작·일시정지·한 단계·0.25×~4× 배속을 지원한다. 카메라, 단면,
  유전체 표시와 품질 설정은 계산 상태를 바꾸지 않는다.
- **기록**: 사건 목록, 자유 입자·완성 입자·방출 수 추이와 직전 실행 비교를 표시한다.
  JSON에는 스키마·모델 버전, 시드, 설정, tick, 요약과 사건이 들어간다.

## 생물학적 경계

캡시드는 단백질 껍질이며 일부 바이러스에서 관찰되는 지질 외피와 다르다. 유전정보는
RNA와 단백질 생산을 거쳐 구조 형성에 관여하지만, DNA가 완성된 3D 좌표를 직접
저장하는 것은 아니다. RNA 유전체 바이러스도 존재한다.

v1 감염 모델은 꼬리 달린 DNA 파지의 **용균 과정**만 일반화한다. 파지 몸체 전체가
세균 안으로 들어가거나 세균을 먹는 것으로 표현하지 않는다. 안정 부착 뒤 유전체가
전달되고 외부에는 빈 입자가 남는다. 그 뒤 숙주 내부의 자원과 합성 활동을 이용해
유전체와 구조 부품이 만들어지고 새 입자가 조립되는 관계를 축약해 표현한다.

모든 바이러스나 파지가 같은 방식으로 용균하지 않는다. 용원성, 만성 방출, 실제 숙주
방어의 분자 기작과 중복 감염은 현재 계산 범위 밖이다. 파지를 세균 억제에 활용할 수
있다는 사실이 모든 파지가 언제나 이롭거나 이 모형이 치료 성과를 예측한다는 뜻은 아니다.

## 근거 등급

화면과 문서에서는 다음 세 등급을 섞지 않는다.

| 등급        | Virus Sim에서의 의미                                            |
| ----------- | --------------------------------------------------------------- |
| 관찰 근거   | 문헌에서 확인한 구조와 생물학적 역할의 관계                     |
| 단순화 모델 | 확산, 접촉, 내부 생산과 조립을 브라우저 계산 상태로 축약한 부분 |
| 가상 조건   | 문헌으로 보정하지 않은 시간, rate, 입자 수와 화면용 크기        |

화면의 시간 단위는 `MT`(model time)이며 실제 초나 분이 아니다. 파지 수는 화면·계산
예산이고 실제 농도가 아니다. 상대 크기는 정규화한 기준 길이를 사용하며, 유전체 선과
일부 부품 두께는 가독성을 위해 과장했다. Three.js의 기하학 세분화 면은 실제 단백질
개수나 T-number를 뜻하지 않는다.

## 계산 모델

계산 코어는 DOM, Three.js와 렌더 루프를 import하지 않는 순수 TypeScript다. 상태를
유일한 사실 원천으로 삼고 3D 장면과 패널은 읽기 전용 snapshot을 투영한다.

### 시간과 재현성

- 고정 간격은 `dt = 1/60 MT`다.
- 동일한 `modelVersion`, 설정, 시드와 tick 수는 같은 상태와 사건 순서를 만든다.
- 시뮬레이션 PRNG는 장식 표현과 분리돼 있다.
- 배속은 프레임당 처리할 고정 tick의 양만 바꾼다.
- 한 프레임당 최대 tick을 제한한다. 처리가 밀리면 시간을 건너뛰지 않고 `계산 지연`을
  표시하면서 모형이 느리게 따라간다.
- 숨겨진 탭에서는 계산을 일시정지하고 누적 시간을 제거한다.

### 이동과 접촉

자유 파지의 각 축 변위 표준편차는 `sqrt(2 D dt)`인 과감쇠 Brownian 모형이다. 세계
경계는 반사 경계다. 세균은 렌더 mesh와 독립적인 capsule로 계산한다. 한 tick의 이동을
최대 0.18 기준 길이 구간으로 나눈 뒤 각 구간에서 표면 교차를 확인해 자유 파지가
세균 내부로 통과하지 않게 한다. 이는 연속 충돌의 해석해가 아닌 문서화된 수치 근사다.

표면 접촉 뒤 인식 조건, 인식 부위 분포와 가역 부착을 계산한다. 사건 확률은 프레임당
상수가 아니라 `p = 1 - exp(-k dt)`인 rate로 관리한다. 이 값은 실제 숙주 특이성을
예측하는 분자 계수가 아니다.

### 상태 전이

개별 파지:

```text
free → contacting → attached → delivering → spent
             ↘ free      ↘ free
```

세균:

```text
susceptible → receiving → producing → assembling → lysing → lysed
                   ↘ blocked (내부 검증 시나리오)
```

첫 성공 전달만 단일 숙주의 감염 주기를 소유한다. 이는 v1의 계산 범위를 제한하는
정책이며 실제 모든 파지가 중복 감염을 차단한다는 뜻은 아니다. 카메라나 꼬리 애니메이션
완료는 상태 전이를 일으키지 않는다.

### 내부 생산과 조립

세균은 남은 자원, 내부 유전체 수, 구조 부품 묶음 수, 완성 입자 수를 가진다. 구조 부품
묶음은 실제 단백질 분자 개수가 아니다. 생산 단계에서 자원을 소비해 유전체와 부품을
쌓고, 조립 단계에서 각각 하나씩 소비해 완성 입자 하나를 만든다. 자원과 개수는 음수가
될 수 없다. 용균이 시작되면 생산과 조립을 중단하며 그 시점의 완성 입자만 방출한다.

모든 계수는 `src/virus-sim/model/presets.ts`에 모여 있다.

| 계수           |           v1 값 | 의미                                       |
| -------------- | --------------: | ------------------------------------------ |
| 확산 계수 D    |            0.64 | 정규화 공간 / MT의 가상 확산 계수          |
| 부착 rate      | 2.2 / 4.6 / 8.2 | 적음 / 기본 / 많음 비교 조건               |
| 해제 rate      |            0.28 | 안정 전달 전 가역 부착 해제 조건           |
| 전달 시간      |          1.4 MT | 설명용 전달 진행 시간                      |
| 생산 시간      |          5.2 MT | 생산과 조립을 구분해 보기 위한 단계 시간   |
| 조립 시간      |          3.1 MT | 보유 부품으로 입자를 조립하는 단계 시간    |
| 용균 시간      |         1.25 MT | 외곽 변화와 방출을 따라보기 위한 단계 시간 |
| 최대 완성 입자 |              14 | v1 화면·계산 예산                          |

## 렌더링 정책

구조와 감염 표현은 절차적 geometry만 사용한다. 캔버스는 독립된 큰 viewport이며
OrbitControls가 회전·줌·이동을 담당한다. 기본 자동 회전, bloom, 안개와 피사계 심도는
사용하지 않는다. 캡시드는 청록, 유전체는 보라, 세균 외곽은 옅은 청색, 선택과 현재
사건은 호박색으로 색과 글자를 함께 사용한다.

반복 파지는 geometry를 공유하고 개별 상태에 필요한 material만 분리한다. 렌더 개수와
계산 개수는 분리되며 패널 숫자는 항상 계산 값을 사용한다. 모바일은 렌더링을 30fps로
제한하고 DPR 상한을 1.5로 둔다. 낮은 품질은 DPR과 장식 별을 줄이되 모형 개체나 계산
조건을 바꾸지 않는다.

## 검증

`tests/virus-sim/simulation.test.ts`에서 다음 계약을 확인한다.

1. 같은 설정·시드·tick의 전체 상태와 사건 순서가 같다.
2. 30fps와 60fps 형태의 렌더 스케줄이 같은 tick에 도달하면 결과가 같다.
3. 인식 불일치에서도 접촉은 일어나지만 전달과 생산은 일어나지 않는다.
4. 감염 주기·용균·방출은 숙주당 한 번이고 방출 수는 완성 입자 수와 같다.
5. 추상 방어 분기는 전달 뒤 생산 없이 종료된다.
6. 자원·부품·개수가 음수가 되지 않고 자유 파지가 세균 안에 남지 않는다.
7. 여러 시드의 평균 제곱 변위가 구현한 3차원 Brownian 모형의 `6Dt`와 명시한 허용
   오차 안에서 일치한다.

전체 저장소는 `npm run lint`, `npm run test`, `npm run build`를 통과해야 한다. 빌드 뒤
`dist/projects/virus-sim/index.html`은 번들 asset을 가리켜야 하며 소스 엔트리를 그대로
포함하면 안 된다.

- `npm run lint`: 통과
- `npm run test`: 31개 파일, 162개 테스트 통과
- `npm run build`: TypeScript 검사와 Vite 다중 페이지 빌드, legacy 복사 통과

- 검증용 브라우저가 작업공간의 localhost 접근을 차단해 1440×900·390×844 실제 화면
  검사는 수행하지 못했다. 공개 반영 전 실제 브라우저에서 겹침, 터치, WebGL 콘솔과
  기본·최대 입자 성능을 다시 확인해야 한다.

## 후속 범위

- 방향성 결합과 가역 결합을 계산하는 별도 자가조립 실험
- 다중 세균·파지, 공간 인덱스, Worker와 반복 분포를 포함하는 집단 모델
- 출처·라이선스·좌표 단위가 확인된 공개 구조 파일 관찰
- 용원성·만성 방출과 문헌으로 보정한 여러 파지·숙주 조합

자가조립과 집단 감염은 v1의 분해 연출이나 단일 실행 결과를 그대로 확장하지 않고 별도
계산 모델과 검증 계약으로 추가한다.
