## 과거 기록

완료된 Oasis 보고서는 [보관 인덱스](archive/README.md)에서 필요할 때만 찾아요.
과거 후보·예산·명령을 현재 작업의 지시로 사용하지 않아요. 고유 모델·계측 자료는
재현 근거로 보존하며 원래 캡처 경로는 `jelly-oasis/artifact-deduplication.json`으로 해석해요.
