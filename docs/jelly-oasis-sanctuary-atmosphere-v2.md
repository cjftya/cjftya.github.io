# Jelly Oasis — Sanctuary atmosphere v2

## 목표와 범위

사용자가 제공한 보라빛 숲과 청록빛 세계수 성소를 기준으로, 하늘·표면·조명·수면·공중·산림을 함께 개선한다. 로우폴리 형태, 세계수 중심 구도, 기존 카메라와 날씨·낮밤 기능을 유지한다. 화면 전체를 안개나 블룸으로 덮는 방식에 의존하지 않는다.

## 변경 내용

- 하늘: 청록·남색 중심의 낮밤 색 구성, 휘어진 빛의 띠와 불규칙한 끊김, 방향성 있는 구름 가장자리 색. 기존 거대 행성과 두 달 유지.
- 조명: 날씨·밤에 반응하는 청록 역광과 보라색 보조광, 세계수 강조광, 호수 주변 민트빛 반사광. 추가 광원에는 그림자 맵을 생성하지 않는다.
- 표면: 세계수와 주변 숲의 잎 색을 공간에 따라 다르게 표현하고, 실제 조명량과 면의 법선에 따라 가장자리 색을 보강한다. 기존 바람·그림자 셰이더와 결합한다.
- 수면: 실제 반사·굴절과 파동 유지. 수심과 물결 무늬에 따라 민트빛을 더하고, 깊은 물에는 반사가 남도록 한다. GPU 중립 디버그 모드에는 발광을 적용하지 않는다.
- 공간: 세계수 주변 서로 다른 높이의 공중 입자와 지면에 연결되는 빛줄기. 빛줄기는 깊이 검사를 사용하는 월드 공간 효과이며 실제 볼륨 광선 추적은 아니다. 기존 낮은 안개 농도는 오히려 줄인다.
- 산림: 북쪽·서쪽·동쪽 산비탈을 내려오는 짧은 나무 군락, 전경 가장자리 군락, 낮은 풀·관목·꽃 연결부 추가. 호수·통로·세계수 주변 제외 영역과 간격 검사는 유지한다.
- 후처리: HDR 블룸 뒤, 톤 매핑과 출력 색공간 변환 전에 절제된 채도·그림자 색 보정 1패스.

## 구현과 비용

- 주요 산비탈·전경 군락은 모바일에서도 유지한다. 기존 주변부 간소화와 입자 수 차이는 유지한다.
- 숲은 기존 9개 인스턴스 드로우를 재사용한다. 식재 수 증가로 실제 삼각형·그림자 렌더링 비용은 증가한다.
- 광원 3개, 빛줄기 메시 1개(20개 삼각형), 화면 색 보정 1패스 추가. 새 이미지 텍스처는 없다.
- 새 효과는 배치 재생성, 낮밤·날씨 전환, reduced-motion, 리소스 해제를 처리한다.

## 검증

- TypeScript·프로덕션 빌드, ESLint 통과.
- 환경·밤/날씨·지형·바람·성소·산림·호수 관련 7개 파일, 34개 테스트 통과.
- 반사 수면·CPU/GPU 파동·호수 전용 경로 추가 검사 통과. 관련 검사 합계 11개 파일, 44개 테스트 통과.
- 낮은 식생의 첫 배치는 기존 5,000 삼각형 예산을 초과해 개수를 조정했다. 예산 상한을 늘리지 않고 재검증을 통과했다. 작은 바위가 0.27m 이상 깊게 묻히는 후보도 제외한다.
- 첫 CI에서 341개 중 340개가 통과했고, 기존 식생 총수 18개를 고정한 검사가 새 군락 때문에 실패했다. 기존 구역 18개와 새 숲바닥 군락 92개를 각각 검사하도록 갱신하고 해당 자산·통로·재배치 통합 검사를 다시 통과했다.
- 새 산비탈 3개와 전경 군락 각각 실제 배치 20개 초과, 빛줄기 재배치/기하 리소스 교체를 회귀 검사에 추가했다.
- **이번 실행에서는 브라우저 제어 기능이 없어 캡처·WebGL 화면·실기기 FPS를 검증하지 못했다.** 따라서 레퍼런스와의 시각적 일치, 과발광·빛줄기 노출 및 모바일 성능은 실제 화면 확인이 필요하다. 정적 빌드 통과는 GPU 셰이더 컴파일/시각 품질 검증을 대신하지 않는다.
