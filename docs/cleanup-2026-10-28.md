## 제거·유지 기준

[중복 경로 대응표](jelly-oasis/artifact-deduplication.json)에 제거 경로, 대표 경로, SHA-256, 바이트 수를 기록했어요. 원본 Git blob과 대표 파일의 바이트가 완전히 같은 경우에만 제거했어요. 문서 참조가 많은 파일을 우선 대표로 남겼고 문서 6개의 이미지 링크를 수정했어요. JPG·PNG·WebP의 내용이 다른 파일은 유지했어요.

과거 QA JSON·manifest의 경로는 당시 출력 경로예요. 원자료의 해시·계측·실행 조건은 재작성하지 않았어요. 원래 이미지 경로가 사라졌으면 대응표의 `removed` → `retained`로 찾아요. 대표 파일의 해시·크기는 `npm run archive:check`로 확인하며 CI에서도 실행해요. 대표 파일은 수정하지 않고 새 검수 결과를 별도 출력 경로에 생성해요.

현재 QA 스크립트의 이미지 입력은 같은 실행에서 생성한 캡처를 읽는 경로이며, 기존 캡처를 외부 입력으로 자동 탐색해 읽는 경로는 확인되지 않았어요. 기본 빌드는 `artifacts/`를 배포하지 않아요. QA 도구는 원래 이름으로 캡처를 다시 생성할 수 있고, 새 미디어는 `.gitignore`로 제외해요. 검토 후 보존할 새 근거만 개별적으로 강제 추가해요. 기존 추적 미디어는 계속 추적돼요.

Blender 원본 12개는 바이트가 모두 달랐고 모델 제작·렌더·감사 기록에 연결되어 있어 유지했어요. 특히 `source-preserved.blend`를 읽는 감사 스크립트가 있으므로 이름만 보고 백업으로 제거하지 않았어요. `loadLandmarkAssets.ts`의 동적 파일명, `layout.json`의 모듈, `startupOptions.ts`의 디버그 선택, 전체 참조 모델 로딩을 대조해 공개 GLB 32개 모두 선택 경로가 있음을 확인했어요. 기본 화면에서 선택되지 않는 GLB도 비교 기능·테스트에 필요해요.

Viola·Wedding Card·공유 파일, Uriel CSV, 의존성·잠금 파일, 앱 소스·테스트, 제작 스크립트, 고유 캡처·연구 기록은 변경하지 않았어요. 테스트가 재생성하는 QA JSON은 커밋에 포함하지 않아요.
