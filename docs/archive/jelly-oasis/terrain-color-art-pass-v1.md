## 원인과 변경

기존 지형 셰이더는 공통 녹색을 기본으로 사용하고, 버텍스 색상을 최대 약 ±5.4%의 약한 틴트로만 반영했어요. 연못 굴착 코드도 전체 메시를 재생성하면서 이전의 높이 기반 녹색 배합을 다시 적용했어요. 따라서 버텍스 색상만 수정하면 실제 화면에 충분히 반영되지 않는 구조였어요.

- `terrainColor.ts`의 공통 색상 함수를 원래 지형과 굴착 지형 양쪽에 적용했어요.
- 버텍스 색상을 셰이더의 실제 바탕색으로 사용해 지역 차이가 보이도록 했어요.
- 기존 `SCENERY_ZONES`의 숲 배치 경로를 따라 숲 바닥의 올리브색이 이어져요.
- 오아시스 좌표, 높이, 실제 굴착 깊이, 넓은 저주파 변화를 사용해 물 주변과 외곽을 구분해요.
- 실제 면의 경사에 따른 흙·암석 배합과 로우폴리 면 표현은 유지했어요.
- 잔무늬의 강도를 낮춰 큰 색 영역이 먼저 보이도록 했어요.

첫 시안에서는 중심의 녹색이 원형에 가깝게 고립되고 외곽이 너무 모래처럼 보였어요. 최종 시안은 숲 바닥을 연결하고, 초원을 더 올리브색으로 조정했어요.

## 전후 화면

같은 카메라·시간·날씨·DPR로 캡처했어요. 이미지 변환 없이 브라우저 PNG 원본을 보관했어요.

전후 PNG 원본은 전달한 `jelly-oasis-terrain-color-v1-recovery.zip`에 보관했어요. 이미지 재인코딩 없이 코드를 반영하기 위해 저장소에는 각 뷰의 검증 수치(`artifacts/jelly-oasis/terrain-color-v1/{before,after}/qa.json`)를 포함했어요.

## 검증 결과

- `npm run lint`: 통과
- `npm test`: 65개 파일, 328개 테스트 통과
- `npm run build`: TypeScript 검사와 프로덕션 빌드 통과
- 브라우저: 데스크톱 1280×800, 모바일 에뮬레이션 390×844 / 844×390
- 전체·중간·연못 근처·암벽 시점, 지형 재생성, 흐린 날, 밤 확인
- 흐린 날과 밤은 날씨 전환 완료(`weatherBlend = 1`) 후 캡처
- 브라우저 JS/셰이더 오류 0건
- 전후 카메라, 오브젝트 경계·접지, 연못 높이, 렌더 리소스 수 자동 비교 통과

- 기존 메시 좌표·노멀·인덱스 해시 검증 및 물 시뮬레이션 테스트 통과

색상 계산은 메시 생성/재생성 때만 수행돼요. 기존 512² 패킹 텍스처 1장과 셰이더의 6회 텍스처 샘플링을 그대로 사용해요. 추가 모델이나 텍스처는 없어요.

실제 휴대폰에서의 FPS는 측정하지 않았어요. 캡처 환경의 한글 폰트가 없어 UI 글자가 사각형으로 보이지만, 변경 전 화면에서도 같으며 UI나 폰트 코드는 수정하지 않았어요. 기존 `THREE.Material: parameter 'side' has value of undefined` 경고는 변경 전후 동일해요.

## 재현

```bash
npm ci
npm run lint
npm test
npm run build
OASIS_QA_BROWSER=/path/to/chromium \
OASIS_QA_OUTPUT=/tmp/oasis-terrain-color \
OASIS_QA_REFERENCE=artifacts/jelly-oasis/terrain-color-v1/before/qa.json \
node scripts/terrain-color-browser-qa.mjs
```

QA 스크립트가 로컬 Vite 서버를 시작하고 종료해요. 기본 브라우저 경로는 기존 프로젝트 QA와 같은 `/tmp/chromium`이에요.
