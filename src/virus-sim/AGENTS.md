# Virus Sim 유지보수

- 기능 개발 완료 버전은 v4.9예요. [유지보수 안내](../../docs/virus-sim.md)를 먼저 읽어요.
- 95종 콘텐츠·모델·출처·설명·레이어와 모바일 UX를 보존하고 최소 변경으로 회귀를 방지해요.
- `catalog/registry.ts`와 `rendering/models/createObservationModel.ts`의 간접 등록을 확인해요.
  이전 버전명이 있는 데이터·설정 키·테스트도 현재 쓰이므로 임의 삭제하지 않아요.
- 관련 검사: 저장소 루트에서 `npx vitest run tests/virus-sim`을 실행해요.
  전체 검사·빌드와 브라우저 점검은 유지보수 안내를 따라요. 미실행 검사는 명시해요.
- 다른 앱·공유 코드·의존성·배포 경로 변경과 대규모 리팩터링은 별도 작업으로 다뤄요.
